# Ganio Link

Ganio Link connects [Ganio](https://app.ganio.studio) to Logic Pro on your Mac.

## Install
1. Download the newest **Ganio-Link-x.y.z.pkg** from [the releases folder](releases/).
2. Open it and follow the installer.
3. Ganio Link appears in your menu bar. Ganio walks you through the rest.

Ganio Link checks for updates itself. Its menu shows **Update available** when a new version is out.

This repository only holds the installers and `latest.json` (what the updater reads).
